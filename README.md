# Personal Portfolio 🌐

As part of this project, I developed a personal portfolio website using HTML & CSS. Using this project, I will be able to show my skills in front end development as well as develop a responsive UI.

---

##  Features

- Responsive UI design for both mobile and desktop devices.
- Scrolling navigation bar.
- Interactive UI design.
- Pages such as about me, projects, skills and contact page.
- Hover effects.
- Elegant UI design.

---

## Technologies Used

- HTML5
- CSS3

---

## Things I Learned

Some things I learned from this project include:

- Responsive web designing
- Positioning of UI elements using flexbox and positioning properties in CSS
- Development of interactive UI elements
- HTML markup language
- Styling of websites
- User Experience

---

## Purpose of This Project

Purpose of this project is to develop a personal portfolio website.
