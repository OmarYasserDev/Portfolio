Personal Portfolio Website
This website is a result of my effort to create something that would demonstrate my skills and knowledge in web development as well as serve as an experiment on creating a responsive interface.

Features
The main goal in making this website was creating a clean, elegant design with a convenient UX. Here are some basic features I tried to implement:

Fully Responsive: The page is able to dynamically change the size of all its components depending on which device it is being viewed on – mobile phone, tablet or PC.

Dynamic Scroll Navigation Bar: The website includes a navigation menu at the top of the page to switch quickly between sections.

Key Sections: There are separate pages dedicated to About Me, Projects, Skills and Contacts to provide full information.

User Interface (UI): This website features clean UI with subtle CSS hover effects.

Technologies Used

Lessons I Learnt
This was a perfect project for me to get better at the fundamentals of web development. Instead of having a framework do all the work, designing the website from scratch taught me how to properly make complicated designs possible through Flexbox and relative/absolute positioning. I got better at ensuring that user experience is a priority when designing interactive interfaces.
